# Document extraction

Check the configured deployment with `deployment_status`. Use the available tool contracts to determine which extraction and verification capabilities the deployment provides. Upload the source with `upload_pdf` and start with `start_full_pipeline`. Enable assembly when the user needs complete structures from variable substitutions. The calling agent handles image and text perception in its current coding session. BioChemInsight handles document processing and graph validation. Keep perception in the agent session throughout the task, including recovery and reconciliation.

Poll `task_status` while the run is active. Use `perception_batch` to retrieve pending prompts and evidence, and fetch the numbered sheets before answering image requests. Submit the fields required by each response schema. Keep the panel numbers intact in `perception_answers`. Requests without images are answered from their text and the supplied context. Resolve an unreadable crop using the source page when available. If evidence still cannot be read, use the contract's uncertainty or rejection fields. Keep polling after a batch until completion, failure, or cancellation.

For activity or ADME results, apply the [measurement evidence rules](../references/measurement-evidence.md). Inspect returned tables with `task_tables` and compare coverage with the requested pages and data. Check [compound identity evidence](../references/compound-identity.md) and assembly evidence before joining measurements. Use `open_review_workspace` to inspect disputed regions. For a local report, download and unpack the result before running `build_extraction_report`. Report gaps that affect the requested result.
