# Compound identity evidence

Use the structure box to anchor the drawing. Inspect neighboring drawings and the labels above, below and to either side before assigning ownership. For PDFs with a text layer, use `read_compound_labels` with the competing boxes from the same page and inspect the returned evidence against the layout. For a missing or disputed match, inspect the corresponding source regions at a readable scale.

Record the complete printed identifier, including its distinguishing suffix. Treat an isolated label prefix as unresolved. When the source gives both an identifier and a systematic name, keep the identifier in the ID field and retain the name as separate evidence where the response contract supports it. Use the source name as the label when it is the only unambiguous designation.

Require clear ownership before using an identifier for measurement joins. Record uncertainty when the label is clipped, the page text and image disagree, or neighboring records compete for the same label.
